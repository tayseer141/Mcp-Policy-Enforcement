Permissions

Permissions come from tools, not from this UI. Every @mcp.tool() function in app/mcp/server.py is auto-synced to a matching permission on server startup. To add a new permission, register a new MCP tool in code — it will appear here on the next boot. The admin's job is to assign these permissions to the right roles.
